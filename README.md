# The World Today — Sunday 22 November 2026

A single image summing up the world's news of Sunday 22 November 2026: 34 verified stories across 7 regions, drawn entirely in code (Python + Pillow). Entry for the make.fun bounty [news-image-20261122](https://make.fun/c/news-image-20261122).

Headline: COP31 collapses — the EU rejects a final text with no fossil-fuel mention, and nearly 200 countries leave Antalya without a deal. Also inside: the Bahrain attack, the Kerch Strait, COP31's record 44-hour overrun, and the day's markets.

`main.ts` copies `entry.png` to `/output/entry.png`; `render.py` draws the image from scratch. Running it twice produces byte-identical output.
